# Samsung Switch Watch 0.11.3-poc 릴리스 노트

릴리스 날짜: 2026-08-05

이번 버전은 v0.11.2 현장 설치에서 확인된 Agent 설치 준비 단계의
`SETUP_UNEXPECTED`를 줄이기 위한 설치 핫픽스입니다. 해당 진단 결과는 패키지 검증 통과 뒤,
로컬 TCP/HTTPS/API 준비 상태 확인 전에 실패했음을 나타냈습니다. Agent API v4, Viewer 장비 관리,
Telnet 명령과 저장 형식은 변경하지 않습니다.

## 설치 흐름 단순화

- 일반 `설치/업데이트`는 읽기 전용 사전 점검과 실제 배포에서 같은 Windows 서비스 정보를
  연속 두 번 조회하지 않습니다.
- 설치에 필요한 검사는 기존 트랜잭션 배포 안에서 한 번 수행합니다.
- 지원 담당자가 요청할 때 사용하는 읽기 전용 진단 모드는 그대로 유지합니다.
- 파일·서비스 변경 전 검사와 실패 시 rollback 계약은 유지합니다.

## Windows 서비스 조회 호환성

- 초기 서비스 상태 조회가 일시적으로 실패하면 200ms 뒤 한 번만 다시 확인합니다.
- 두 번째 조회도 실패하면 민감한 예외 원문을 노출하지 않고 `SETUP_SERVICE_FAILED`로
  분류하며, 서비스·파일·방화벽을 변경하지 않습니다.
- 기존 서비스의 구성과 실행 상태는 읽을 수 있지만 보안 설명자만 읽을 수 없는 환경에서는
  조회 가능한 상태를 보존해 설치를 계속하되 기존 서비스 보안 설정은 변경하지 않습니다.
  설명자를 확보한 경우에만 새 제한 DACL을 적용하고 실패 시 원래 DACL까지 복원합니다.
- 실제 설치 결과에도 초기 상태를 `SERVICE_NOT_INSTALLED`, `SERVICE_RUNNING` 또는
  `SERVICE_STOPPED`로 기록하여 다음 SWD1 코드의 `UNKNOWN` 범위를 줄였습니다.
- 상태를 읽은 기존 서비스가 파일 교체 전에 사라지면 같은 이름의 새 서비스를 임의로 만들지
  않고 `SETUP_SERVICE_FAILED`로 중단하여 기존 보안 설정을 추측하지 않습니다.
- 기존 서비스는 실행 상태 표기의 모호함과 관계없이 제한 시간 중지 확인을 통과해야만 파일을
  교체합니다. 중지 과정에서 오류가 나면 rollback에서도 중지를 다시 확인하고, 확인되지 않으면
  파일과 서비스를 임의로 복구하지 않습니다.
- 신규 설치 rollback에서 서비스 삭제 API 호출 성공만으로 완료 처리하지 않고, Windows 서비스가
  실제로 사라질 때까지 최대 20초 동안 확인합니다.

## 설치 방법

공식 Release의 다음 두 ZIP을 같은 버전으로 사용하십시오.

```text
SamsungSwitchWatch-Agent-0.11.3-poc-win-x64.zip
SamsungSwitchWatch-Viewer-0.11.3-poc-win-x64.zip
```

Agent ZIP을 로컬 폴더에 완전히 압축 해제하고 `SamsungSwitchWatch.Agent.Setup.exe`를 실행한
뒤 UAC를 승인합니다. `설치/업데이트`는 한 번만 누르십시오. Viewer도 기존 프로세스를 완전히
종료한 뒤 새 ZIP을 별도 로컬 폴더에 압축 해제해 실행합니다. Python, PowerShell 스크립트 허용,
온라인 패키지 또는 별도 .NET 설치는 필요하지 않습니다.

## 검증 범위

자동 테스트에는 일시적 서비스 조회 실패 뒤 성공, 지속 실패의 안정 코드 변환, 변경 전 중단,
서비스 상태 진단 보존, 읽기 전용 서비스 접근권한, 서비스 상태 경합과 실제 삭제 완료 대기,
기존 설치·복구 회귀 검증을 포함합니다.
실제 사내 EDR·서비스 DACL·UAC 조합은 외부 개발 환경에서 증명할 수 없습니다. 승인된 Agent PC
한 대에서 먼저 설치하고, 실패하면 새 화면의 SWD1 지원 코드만 전달하십시오.

장비 모델 자동 판별은 이 설치 핫픽스의 현장 성공을 확인한 다음 별도 단계로 진행합니다.
