# Samsung Switch Watch 0.11.1-poc 릴리스 노트

릴리스 날짜: 2026-08-05

이 버전은 IES4224GP에서 로그인 확인은 성공하지만 포트 상태와 시스템 로그 수집이 약 30초 뒤
`COMMAND_TIMEOUT`으로 끝나는 문제를 개선합니다. Agent 설치·연결 구조와 API v4의 기존 요청 및
성공 응답 형식은 유지합니다.

## Telnet 명령 호환성

- 고정 30초 전체 제한을 `30초 무응답 제한 + 90초 전체 제한`으로 분리했습니다.
- Telnet NAWS 화면 크기를 160×200으로 협상해 불필요한 페이지 중단을 줄였습니다.
- ANSI 제어문자, 백스페이스와 안내 접미사가 포함된 Samsung 계열 페이징 문구를 처리합니다.
- 명령당 페이지 진행은 최대 32회이며, 전체 출력과 세션 제한은 계속 유지합니다.
- 로그인 때 확인한 프롬프트를 정규화해 비교하되 임의의 `#` 또는 `>` 출력 줄은 프롬프트로
  오인하지 않습니다.

## 수집 실패 격리

- 자동 감시에서 포트 상태와 시스템 로그를 순차적인 단일 명령 요청으로 실행합니다.
- 한 수집 항목이 명령 시간 초과·출력 한도로 실패해도 다른 항목을 계속 수집합니다.
- 성공한 결과는 보존하고 실패한 항목만 `확인 불가`로 표시합니다.
- 실패 명령을 같은 수집 주기에 즉시 재시도하지 않으며 장비당 동시 Telnet 세션은 계속 1개입니다.
- 인증·enable·TCP·세션 종료는 반복 로그인을 막기 위해 해당 장비의 현재 수집 주기를 중단합니다.

## 진단과 화면 안내

- `COMMAND_TIMEOUT` 응답에 안전한 단계, 제한된 소요 시간, 출력 수신 여부와 페이지 진행 횟수를
  선택적으로 포함합니다. IP, 계정, 명령과 원문 출력은 포함하지 않습니다.
- 기존 오류 코드와 API v4 응답을 계속 지원합니다.
- 기존 `접속 시험`은 실제 명령을 실행하지 않는다는 의미를 명확히 하기 위해 `로그인 확인`으로
  표시합니다. 포트·로그 명령은 수집 진단에서 별도로 확인합니다.
- 명령 결과의 세션 수, 미니 창의 미감시 수와 장애 팝업의 지속 시간이 잘리지 않도록 표시 폭과
  줄바꿈을 조정했습니다.

## 설치와 업데이트

공식 Release의 다음 두 ZIP을 같은 버전으로 사용하십시오.

```text
SamsungSwitchWatch-Agent-0.11.1-poc-win-x64.zip
SamsungSwitchWatch-Viewer-0.11.1-poc-win-x64.zip
```

Agent PC에서는 새 ZIP을 완전히 압축 해제한 뒤 `SamsungSwitchWatch.Agent.Setup.exe`의
`설치/업데이트`를 실행합니다. Viewer는 기존 프로그램을 종료하고 새 Viewer ZIP을 별도 폴더에
압축 해제해 실행합니다. Python 또는 별도 .NET 설치는 필요하지 않습니다.

## 검증 범위

자동 검증은 합성 Telnet 서버와 비식별 Fixture를 사용합니다. 실제 IES4224GP 펌웨어, 사내
EDR·방화벽·라우팅과 운영 장비 응답은 증명하지 않습니다. 사내에서는 영향이 적은 IES4224GP 한
대에서 로그인 확인 후 포트 상태와 시스템 로그 수집을 10회 연속 검증한 다음 대상을 확대하십시오.
이번 POC의 자동 감시 검증·지원 범위는 등록 장비 10대 이하입니다.
