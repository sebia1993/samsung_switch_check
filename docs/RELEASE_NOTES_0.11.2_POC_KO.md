# Samsung Switch Watch 0.11.2-poc 릴리스 노트

릴리스 날짜: 2026-08-05

이 버전은 Agent 설치 패키지 검증 뒤 제품 폴더를 확인하는 과정에서 현장 접근·I/O 오류가
`SETUP_UNEXPECTED`로만 표시되던 문제를 개선하는 설치 핫픽스입니다. Agent API v4와 Viewer의
장비·자격 증명·감시 데이터 형식은 변경하지 않습니다.

## Agent Setup 안정성

- 기존 Windows 서비스 정보 조회에 전체 제어 권한 대신 구성·상태·보안 설명자 읽기에 필요한
  최소 권한만 요청합니다.
- 제품 폴더 검사 중 `UnauthorizedAccessException`, `SecurityException`과 일반 I/O 오류는
  `SETUP_PATH_NOT_WRITABLE`로 분류합니다.
- 잘못된 경로 형식, 지원하지 않는 경로와 긴 경로는 `SETUP_PATH_INVALID`로 분류합니다.
- 검사 중 잠시 사라진 하위 파일이나 폴더는 해당 항목만 한 번 다시 확인합니다. 다시 확인해도
  실제로 사라진 비루트 항목은 건너뛰며, 그 밖의 지속적인 접근·I/O 오류는 숨기지 않고 설치를
  중단합니다.
- 설치·데이터 경로의 신뢰 검사와 4,096개 항목 제한은 그대로 유지합니다.

## 지원코드와 화면 안내

- 서비스 조회 직후 설치됨·실행 중·중지됨 상태를 먼저 기록합니다. 이후 경로 검사에서
  실패해도 지원코드의 서비스 상태가 `UNKNOWN`으로 사라지지 않습니다.
- 제품 폴더 오류 화면은 로컬 HTTPS나 방화벽 문제가 아님을 안내합니다.
- 오류 원문, 절대 경로, Windows 사용자명과 보안 제품명은 화면·로그·지원코드에 포함하지
  않습니다.
- 같은 실패가 반복되면 제품 폴더나 ACL을 수동으로 삭제·변경하지 말고 화면의 짧은 지원코드만
  전달하십시오.

## 설치와 업데이트

공식 Release의 다음 두 ZIP을 같은 버전으로 사용하십시오.

```text
SamsungSwitchWatch-Agent-0.11.2-poc-win-x64.zip
SamsungSwitchWatch-Viewer-0.11.2-poc-win-x64.zip
```

Agent ZIP을 새 로컬 폴더에 완전히 압축 해제하고 `SamsungSwitchWatch.Agent.Setup.exe`를
실행한 뒤 UAC를 승인합니다. Viewer는 기존 프로그램을 종료한 뒤 새 Viewer ZIP을 별도 폴더에
압축 해제해 실행합니다. Python, PowerShell 스크립트 실행 허용 또는 별도 .NET 설치는 필요하지
않습니다.

## 검증 범위

자동 테스트는 경로 예외 분류, 일회성 I/O 재시도, 최소 서비스 조회 권한, 지원코드 상태와
설치 전 무변경 계약을 검증합니다. 실제 사내 EDR·서비스 ACL·UAC와 전체 설치 경로는 증명하지
않습니다. 승인된 Agent PC 한 대에서 먼저 설치 또는 업데이트한 뒤 서비스 실행과 Viewer 연결을
확인하십시오. 현장 설치가 확인되기 전에는 장비 모델 자동 분류 기능을 다음 릴리스에 포함하지
않습니다.
