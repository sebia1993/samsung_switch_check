# Samsung Switch Watch 0.10.12-poc 릴리스 노트

이번 버전은 기존 Agent 검사 호환성, Agent Setup 진단, Viewer 상태 정확성과 연결 자원 정리,
실제 배포 ZIP의 실행 가능성 검사를 보강한 안정성 릴리스입니다. Agent API v4, Viewer의
장비·자격 증명 소유, 한 줄 읽기 전용 `show` 명령, 장비·감시 데이터 저장 형식과 네트워크
보안 경계는 변경하지 않습니다. 비식별 진단 v1에는 선택 확장 키를 하위 호환으로
추가했습니다.

## Agent 준비 상태 확인

- Setup 사전 점검은 실행 중인 구형 API v4 Agent가 반환하는 최소 `/health/ready` 응답도
  `status=ready`, `apiVersion=4`이면 준비 상태로 확인합니다.
- 선택 필드가 있는 응답에서는 HTTPS 프로토콜과 비어 있지 않은 제품 버전을 계속
  검증합니다. 잘못된 형식, 다른 API 버전 또는 HTTP 프로토콜을 준비 완료로 인정하지
  않습니다.
- 새 Agent 설치·업데이트의 완료 판정은 이전처럼 HTTPS 프로토콜과 새 패키지의 정확한 제품
  버전을 모두 요구합니다. 사전 점검 호환성이 구형 Agent를 새 버전 설치 성공으로
  오인하게 하지 않습니다.
- 준비 응답은 예상 버전 유무와 관계없이 제한된 크기로 읽고 JSON 형식을 확인합니다.

## Agent Setup 비식별 진단

- 예상하지 못한 실패가 발생하면 Setup이 마지막 안전 단계와 오류 범주를 기록합니다.
- 단계는 권한, 작업 기록, 입력, 패키지, 파일 시스템, 서비스, 방화벽, readiness, 복구 등으로
  구분하고 오류는 접근 거부, I/O, 시간 초과, Windows API, 잘못된 상태와 플랫폼 범주로
  제한합니다.
- 해당 단계와 전체 작업의 소요 시간은 제한된 밀리초 값으로 기록합니다.
- `SSW_FIELD_DIAGNOSTIC/1`은 기존 필드를 유지하면서 최초 실패 코드, 실패 범주와 실패 단계
  소요 시간을 선택 확장 키로 추가하며 재생 도구는 기존 파일과 새 파일을 모두 읽습니다.
- 예외 원문, 실제 PID, IP/CIDR, 사용자명, 경로, 방화벽 원문과 장비 정보는 기록하지
  않습니다.
- 진단을 남겼다는 이유로 실패를 성공 처리하지 않으며 기존 사용자용 실패 코드와 복구
  흐름을 유지합니다.

## Viewer 상태 정확성과 연결 정리

- 주기 감시를 켠 장비는 첫 자동 수집이 완료되기 전까지 `확인 대기`로 표시하고 정상 장비
  수에 넣지 않습니다.
- 접속 시험이나 수동 명령이 같은 장비를 사용 중이라 자동 수집이 미뤄지면 이전 결과를 현재
  정상으로 단정하지 않고 `확인 대기`로 표시한 뒤 다음 주기에 다시 시도합니다.
- Agent 연결이 끊기면 현재 확인 불가와 마지막으로 확인한 상태를 구분합니다.
- Agent 연결 교체 또는 Viewer 종료 중에는 진행 중인 HTTP 요청을 취소하고 작업이 끝난 뒤
  이전 클라이언트 자원을 정리합니다.
- 연결 정리가 제한 시간을 넘거나 실패하면 무시하지 않고 비식별 진단 코드로 남깁니다.

## 배포 ZIP 실행 smoke 검사

- 패키지 계약 검사 뒤 Agent와 Viewer ZIP을 새 임시 폴더에 다시 압축 해제합니다.
- 설치된 .NET 런타임과 인터넷 프록시에 의존하지 않는 조건에서 Viewer의 애플리케이션
  리소스와 화면 리소스를 검사합니다.
- Agent Setup은 WPF 리소스와 Agent 실행 파일, 네이티브 WPF 파일 및 BUILD-MANIFEST가
  실제 ZIP에 함께 있는지 검사합니다.
- Mock Agent 실행 파일은 제한된 임시 HTTP 포트에서 준비 상태, identity, 접속 시험과
  합성 `show port status` 요청을 확인한 뒤 종료합니다.
- 이 smoke는 관리자 권한이 있는 Windows CI 또는 승인된 시험 PC에서 제한 시간 안에
  실행하며 임시 프로세스와 폴더를 정리합니다.

## 호환성과 유지되는 동작

- Agent와 Viewer는 같은 `0.10.12-poc` Release 조합을 사용합니다.
- Agent는 창이나 트레이 아이콘 없이 Windows 서비스로 실행됩니다.
- Viewer는 관리자 권한과 설치 스크립트가 필요 없는 포터블 실행 파일입니다.
- Agent API는 HTTPS/TCP 18443, Viewer 고정 IPv4 `/32`, 자동 TOFU 신뢰를 유지합니다.
- Viewer가 장비 IPv4·ID·PW·선택적 enable PW와 감시 이력을 소유합니다.
- Agent는 허용된 한 줄 읽기 전용 `show` 명령을 요청마다 새 Telnet 세션으로 실행하고
  종료합니다.
- 사용자가 인증서 SHA-256 지문이나 페어링 토큰을 입력하는 절차는 없습니다.

## 검증 범위와 남은 현장 확인

자동 검증은 구형·현재 readiness payload, 엄격한 설치 버전 판정, 제한 크기·비정상 JSON,
Setup 단계·범주·시간 진단, Viewer 요청 취소·연결 교체·종료 경쟁, 첫 수집·수집 지연·연결
단절 상태, 패키지 계약과 추출된 실행 파일 smoke 및 전체 회귀 테스트를 포함합니다.

다음 항목은 자동 검증만으로 증명되지 않았습니다.

- IES4224GP, IES4028XP, IES4226XP 실제 펌웨어의 Telnet 프롬프트, 명령과 출력
- 사내 EDR·백신·AppLocker·WDAC가 설치·파일 교체·서비스 시작에 미치는 영향
- 원격 Viewer PC와 Agent PC 사이의 실제 방화벽·라우팅·고정 출발지 주소
- 관리자 권한이 필요한 Agent Setup의 전체 Windows 서비스·방화벽 설치 및 rollback 통합

사내에서는 공식 Agent ZIP과 Viewer ZIP을 같은 Release에서 받아 시험 PC 한 대, 단일 Viewer
연결, 영향이 적은 단일 스위치의 읽기 전용 명령 순서로 확인한 뒤 단계적으로 확대하십시오.
자동 테스트 통과를 실제 삼성 스위치 또는 사내 보안 환경 검증으로 해석하지 마십시오.
